## 解压后验收

在解压所得 `帮助_交接包` 目录中执行：

```powershell
python -m pip install -r requirements.txt
python scripts/verify_delivery.py --parts-dir "D:/收到的影像分卷目录"
```

原7片放在交接包同级目录时，也可以双击包内 `验收.bat`。完整通过必须同时满足 `local_package_passed=true` 和 `complete_delivery_passed=true`。
