# 第二问运行说明（VS Code / CMD / PowerShell）

工作目录为仓库中的：

`第二问\07_正式模型_外源数据融合`

## 一、正常情况下只重跑模型

在 VS Code 打开终端。

CMD：

```bat
cd /d "第二问\07_正式模型_外源数据融合"
python run_models.py
```

PowerShell：

```powershell
Set-Location ".\第二问\07_正式模型_外源数据融合"
python .\run_models.py
```

这一步不下载数据，也不重新读取数千个 MODIS/SMAP 原始文件。

## 二、单独画图

```bat
python scripts\10_plot_results.py
```

只在`figures`文件夹输出 7 张 PNG；不输出 PDF，不画流程图，不重建缓存。

## 三、什么时候才运行预处理

只有原始数据、源区范围或`config/model_config.json`改变时才运行：

```bat
python run_preprocessing.py
```

其中 SMAP 需要扫描约 4900 个小文件，耗时明显高于其他步骤，但生成缓存后无需重复扫描。

## 四、环境

若新电脑缺库：

```bat
python -m pip install -r requirements.txt
```

推荐 Python 3.11。绘图若中文显示为方框，请在 Windows 中确认“微软雅黑”或“黑体”可用。
