# 第二问正式模型：外源数据融合

本模块是第二问重新建模后的正式工作区。此前`04—06`目录中的线性、软链和统一判级实验保留为历史探索，不作为最终结果直接引用。

正式模型采用以下结构：

1. 源区静态易失稳性：地形、冰厚、冰川速度、长期变薄、物源和沟道连接性；
2. 冰冻圈热力分支：源区订正气温、短波辐射、灾前可获得反照率和ETI融水；
3. 降雨—水分分支：IMERG降水、ERA5-Land降水与SMAP土壤湿度；
4. 综合触发评价：静态条件与动态触发不可完全补偿，输出统一风险指数与等级；
5. 可靠性：历史背景超越率、事件提前量、空间分块验证以及参数/窗口敏感性。

统一口径：2021—2024年为背景，2025年完全隔离，2026年8月26日为主事件。灾后信息只用于源区和路径验证。

缓存与绘图严格分开：

- `run_preprocessing.py`：重建 MODIS、CHIRPS、SMAP 和多源逐小时缓存；仅在原始数据或参数改变时运行。
- `run_models.py`：读取缓存，重跑时间阈值、空间模型、统一风险、GFS 核查和背景审计。
- `scripts/10_plot_results.py`：只读取既有结果并输出 PNG，不会重跑缓存或模型，也不生成流程图。
- `run_supplements.py`：重跑新下载的 MCD43、Sentinel-1/2、Landsat、MERIT、JRC、WorldCover 和新冰湖目录补充实验；不下载数据。
