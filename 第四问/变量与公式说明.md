# 第四问变量与公式说明

## 1. 分阶段灾害链

本题不是普通降雨型泥石流。计算链分为：

`高位冰岩崩塌 → 撞击沟床并转化为水石混合物 → 峡谷高速传播 → 河谷汇流与侵蚀卷入 → 口岸及下游影响`

高位自由落体阶段不满足浅水假设，因此二维方程不从“坡顶静水柱”开始，而从上游里程0—600 m沟道转换带开始。二维传播阶段的有效入沟体积在有限历时内注入，并按局地最陡下降方向赋予经能量耗散后的有效初速度。该量不是高位源区总崩塌方量。

## 2. 二维深度平均守恒方程

状态量为：

- `h`：混合物流深；
- `u,v`：深度平均速度；
- `z`：床面高程。

质量守恒：

`∂h/∂t + ∂(hu)/∂x + ∂(hv)/∂y = E`

动量守恒采用浅水方程通量，地形源项使用水静力重构处理，使静水状态尽可能保持平衡。干湿前缘由HLL通量和CFL自适应步长处理。

## 3. Voellmy–Salm摩阻

标准底部剪应力：

`S = μρgh cosθ + ρg|U|²/ξ`

除以单位面积质量`ρh`后，速度方向的阻力减速度为：

`a_f = μg cosθ + g|U|²/(ξh)`

其中：

- `μ`控制低速阶段和停止距离；
- `ξ`控制高速阶段的速度平方阻力，单位为m/s²；
- `θ`为局地坡角。

模型在上游0—10 km与10 km以后的河谷段使用不同`μ、ξ`。这些是栅格尺度有效参数，不是可直接外推的材料常数。

官方参考：

- RAMMS Debris Flow Manual：https://ramms.ch/wp-content/uploads/RAMMS_DBF_Manual.pdf
- RAMMS Friction Parameters：https://ramms.ch/ramms-debrisflow/friction-parameters/

## 4. 侵蚀卷入

M3采用可解释的速度阈值形式：

`E = k_e max(|U|-u_c, 0)`

并受每个栅格的最大可侵蚀厚度`d_e`限制。源区转换带不重复计算卷入；上游陡坡的可侵蚀厚度按河谷值的40%设置，避免有效入沟体积与卷入体积重复计数。

## 5. 模型层级

|模型|作用|是否输出流深/速度/到时|
|---|---|---|
|M0 路径模型|检查沟谷连通与传播方向|否|
|M1 均一Voellmy|普通泥石流参数基线|是|
|M2 分区Voellmy|允许源区和河谷运动状态不同|是|
|M3 分区＋卷入|描述运动过程中体积增长|是|
|M4 有效情景集合|表达参数不确定性|输出条件超阈比例和分位数|

## 6. 评分与验证

60 m筛选综合得分：

`Score = 0.50 S_arrival + 0.30 CSI_cal + 0.20 Recall_cal`

其中：

`S_arrival = exp(-|t_sim-463|/120)`

空间评价采用：

- `CSI = TP/(TP+FP+FN)`；
- `Recall = TP/(TP+FN)`；
- `Precision = TP/(TP+FP)`。

源区至口岸范围用于校准；口岸以下至30 km范围留出检验，不进入得分。因而留出区CSI可以用于判断空间迁移，而不能把调参区表现冒充独立验证。

## 7. M4条件空间范围

对每个像元：

`p(x)=Σ w_k I[h_max,k(x)≥0.5 m]`

分区：

- 核心区：`p≥0.975`；
- 主要可能区：`p≥0.50`；
- 外包络区：`p≥0.025`。

这些阈值表示保留情景中的条件覆盖比例，不是国家法定风险等级，也不是灾害真实发生概率。
