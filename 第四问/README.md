# 第四问：2026年高位冰岩崩塌—泥石流链二维动力学回放

## 一、已完成内容

本目录已经完成第四问的可复现实验，不再只是方案：

1. 建立高位崩塌源区、沟道转换带和下游河谷的分阶段表达；
2. 采用二维深度平均浅水方程计算最大流深、速度和首次到达时间；
3. 底部阻力采用标准Voellmy–Salm形式，并区分源区—峡谷段与河谷段有效参数；
4. 加入可开关的侵蚀卷入项；
5. 先在60 m网格上进行54组拉丁超立方筛选，再完成5组初筛和24组加密、共29组30 m复算；
6. 用源区至口岸到时和上游卫星范围作校准，将口岸下游卫星范围留出检验；
7. 形成M0路径、M1均一基线、M2分区摩阻、M3分区＋卷入、M4有效情景集合；
8. 从29组30 m结果中保留20个行为合理情景形成M4集合，并把最大流深、速度、到时、冲击强度、侵蚀厚度、条件超阈比例和三档空间范围回接到第三问；
9. 增加传播快照、全活动域敏感性和冲击强度代理量，对参考论文中可复核的优点进行独立增强。

## 二、最重要结论

- 事件起算采用`2026-08-26 02:52:10 UTC`（北京时间10:52:10）的源区地震学起始时刻；口岸前缘约为`02:59:53 UTC`，相差463 s。**没有把10:30初报时间当作发生时刻。**
- 二维模型的基准量是沟谷转换带的**有效入沟体积**3542万m³，并在2800万—4300万m³范围扰动；它不是高位崩塌源区总方量。此前随手写出的“5860万”没有进入模型。
- 普通常用量级的均一Voellmy参数M1在12组实验中均未于1100 s内到达口岸，说明普通均一泥石流假设不足。
- 30 m复算中，M2和M3均能再现快速到达。参数搜索与集合权重只使用口岸到时和上游校准区；固定行为集合后，以`0.70×校准得分+0.30×下游留出CSI`选定稳健主情景`R3_011`。
- `R3_011`：口岸到时454.0 s，较463 s早9.0 s；校准区CSI为0.607，口岸下游留出区CSI为0.596；有效入沟约3727万m³、卷入约1408万m³、末态约5137万m³。
- 口岸单元最大流深约36.6 m、最大速度约47.3 m/s。全域最大流深122.6 m位于上游峡谷，不能写成口岸流深；动态压力仅是`0.5ρv²`代理量，不能等同结构设计荷载。
- 20个30 m行为合理情景的GLUE式加权平均到时为459.2 s；情景P10—P90为440.8—475.9 s。叠加CCTV约±60 s时钟不确定性后，观测感知区间为380.8—535.9 s。
- 相同情景的30 m到时比60 m早约82—99 s，表明分辨率—地形离散敏感性不可忽略；30 m结果不能包装成工程级精确预报。
- 以`P(h_max≥0.5 m)`划分条件情景范围：核心区7.56 km²、主要可能区9.16 km²、外包络区10.86 km²。
- 去除600 m活动带限制后的全地形复算仍得到454.0 s到时，且全域CSI为0.471、精确率为0.975，说明主路径不是被活动带边界人为“画”出来的。
- 没有采用“全域铺设0.5 m静水层”的河流敏感性：该设定会产生非物理坡降波。后续若研究河流汇流，必须使用有来源的上游流量过程线或边界水位。

## 三、目录

- `config/model_config.json`：事件约束、网格、搜索范围和评分权重；
- `scripts/01_prepare_inputs.py`：输入审计、裁剪、观测栅格化；
- `scripts/q4_solver.py`：二维守恒方程、Voellmy摩阻、分区和卷入；
- `scripts/02_run_models.py`：M1—M4筛选、30 m复算和集合；
- `scripts/03_analyze_and_plot.py`：统计表、GeoTIFF、第三问回接和PNG图；
- `scripts/04_run_extensions.py`：动态快照、宽域复算及被拒绝扩展的审计记录；
- `outputs/`：最终数值结果；
- `figures/`：可直接筛选进入论文的PNG；
- `交接文件/`：论文写作、证据边界和图表建议。

## 四、结果边界

本结果是对2026年事件的**条件回放与机制检验**，不是已具备实时资料流的业务预警系统。M2/M3中的摩阻系数是30—60 m栅格尺度的有效参数，不应直接移植为其他沟谷的材料常数；UNOSAT范围是初步卫星解译，也不等同逐点现场测量。对方论文中有逻辑依据的集合扩充、动态快照和宽域检验已吸收；未经独立核实的硬体积、硬坝高及循环验证没有采用。
