# 第四问论文交接README

## 一、正文建议结构

### 4.1 问题重述与建模边界

强调2026年事件为高位冰岩崩塌触发的链式灾害，而不是单一降雨型泥石流。第四问回答的是在给定源区启动与体积条件下，物质如何传播、多久到达、影响多大；不重复第三问的天气触发预报。

### 4.2 数据与证据等级

正文应列出：30/60 m地形网格、源区多边形、UNOSAT初步灾后范围、源区起始时刻、口岸CCTV前缘时刻。明确CCTV坐标和时钟不是现场测量级真值；UNOSAT范围用于灾后回放。

### 4.3 方程与物理设定

依次写：二维浅水守恒方程、Voellmy–Salm摩阻、源区—河谷分区、侵蚀卷入、干湿前缘和CFL。高位崩塌阶段通过沟道转换带入流表达，避免把自由落体错误当成浅水流。

### 4.4 基线—升级—集合

- M0只回答路径；
- M1为均一普通泥石流基线；
- M2证明分区低摩阻对再现快速长程传播的必要性；
- M3检验卷入对覆盖范围和体积增长的作用；
- M4用20个30 m行为合理情景表达参数不确定性。

### 4.5 参数筛选与验证

写清54组60 m筛选、29组30 m复算（5组初筛＋24组加密）、物理淘汰、校准区和留出区。参数搜索和GLUE权重不使用口岸下游留出区；在行为集合固定后，才以`0.70×校准得分+0.30×留出CSI`选稳健代表情景，避免把一次最佳训练拟合包装成唯一真值。

### 4.6 结果

推荐正文表：

还必须单列网格敏感性：相同参数在30 m上的到时比60 m早约82—99 s。这同时包含像元分辨率和地形离散差异，说明模型能够支持事件回放和相对空间判断，但不应宣称达到工程预警所需的秒级精度。

`R3_012`校准表现最佳，`R3_020`留出表现最佳，`R3_011`在预设70/30稳健规则下综合最好，故作为论文代表情景；M2仍作为无卷入基线。正文应同时报告这一分工，不得宣称R3_011在每个单项指标上都最优。

## 二、不能写错的地方

1. 10:30是早期报告时间，不能写成物理触发时刻；
2. 10:52:10是源区起始，10:59:53是口岸前缘，不是同一个地点的两个版本；
3. 3542万m³是二维沟谷传播的有效入沟体积中心，不是高位源区总崩塌方量；不要再写未经核实的5860万；
4. 122.6 m是上游峡谷网格最大值，口岸约36.6 m；
5. M4是有效参数情景比例，不是未来泥石流发生概率；
6. `μ、ξ`是本次事件和网格尺度下校准的有效参数，不能直接当地区通用常数；
7. UNOSAT是初步遥感解译，不能写成现场实测淹没边界；
8. 当前没有完整现场流深、堆积厚度和逐点速度数据，验证仍受限。
9. 动态压力为`0.5ρv²`代理量，不是桥梁或建筑的设计冲击荷载；
10. 全域铺设静水层会形成非物理坡降波，已作为失败扩展排除，不得写成有效敏感性结果。
