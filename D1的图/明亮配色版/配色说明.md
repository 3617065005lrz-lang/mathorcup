# 明亮配色版

在期刊彩色版基础上仅调整颜色，沿用数值、统计与布局。

图2：青绿#29C7A5、珊瑚红#FF805C、金黄#F5BE3D、天蓝#29A8E0、浅紫#A38BE4分别区分最终五因素；其余灰色。
图3：统一浅黄#FFF9E8—薄荷#9DE9DC—青色#29A8C7顺序色标，深色字确保数字清楚。
图4：历史珊瑚红，事件天蓝，保留深色中位线、须线与全部观测。

每张同时输出纯矢量SVG与600 DPI PNG。原版本保留。运行同目录绘图.py可复现；依赖matplotlib、pandas、numpy、pyarrow，读取项目现成plot_cache。

技能及研究来源见上一版“期刊彩色版/参考与配色说明.md”。科研绘图技能工具文献：Kassis等(2026), Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents, https://doi.org/10.48550/arXiv.2609.00065 。
