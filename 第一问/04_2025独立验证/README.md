# 2025年事件独立验证

本目录使用2025年7月8日Purepu冰川冰面湖溃决事件，对2026年主分析已经冻结的五个特征进行独立验证。

## 冻结原则

- 不重新筛选特征。
- 不改变五个特征的计算公式和预期方向。
- 不把2025年加入历史背景或标准化尺度。
- 历史背景仍只使用2021—2024年。
- 不因2025年结果好坏回头调整2026年模型。

## 事件口径

- 首次报告影响：2025年7月8日05:30，北京时间。
- 上述时间是洪水在吉隆—Rasuwagadhi边境口岸的首次报告影响时间，不是源区开始排水时间。
- 主验证截止时刻：04:00，即事件所在小时之前的最后一个完整小时。
- 时间敏感性截止时刻：05:00。
- 源区：Purepu冰川冰面湖，28.402561°N、85.646705°E、海拔约5160 m。
- 机制：冰面湖快速排水引发冰湖溃决洪水，并沿河侵蚀、裹挟固体物质形成跨境山洪泥石流灾害链。

## 冻结的五个特征及2026预期方向

1. 剖面土壤含水量24小时变化：偏低。
2. 24小时平均2米气温：偏高。
3. 24小时累计正净辐射：偏高。
4. 72小时累计降水：偏低。
5. 24小时平均2米相对湿度：偏低。

## 验证规则

- 主场景：严格QC版、截止04:00、评价窗口24小时、历史精确同日。
- 敏感性场景：2个截止时刻 × 3个评价窗口 × 4个历史日期带 × 2个QC版本，共48个场景。
- 方向支持：2025年偏离方向与2026年冻结方向一致。
- 强支持：方向一致，且方向性历史百分位不低于80%。
- 预设综合判据：
  - 强验证：主场景至少4/5方向一致、至少3/5强支持，且不少于75%的敏感性场景达到4/5方向一致；
  - 部分验证：主场景至少3/5方向一致、至少2/5强支持，且不少于75%的敏感性场景达到3/5方向一致；
  - 否则记为未获得支持。

这些等级只用于本项目内部概括；论文仍应报告逐项数值和敏感性结果，不能将其解释为因果验证。

## 运行

在VS Code、CMD或PowerShell进入本目录后运行：

```cmd
python .\scripts\01_validate_2025_event.py
```

结果写入`outputs/`。本脚本只计算表格与报告，不生成图片。

若只需根据已经生成的结果绘制验证图，可单独运行：

```cmd
python .\scripts\02_plot_2025_validation.py --dpi 300
```

该绘图脚本只读取`outputs/01_2025主验证五特征.csv`和`outputs/04_2025特征稳定性汇总.csv`，不会重新读取逐小时数据或重新计算48个场景。图片只输出PNG，保存在`figures/`。
