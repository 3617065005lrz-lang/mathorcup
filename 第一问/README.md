# MathorCup 赛道B第一问：代码与论文交接说明

## 1. 本目录解决什么问题

赛题第一问要求基于气象梯度数据（MET）、辐射数据（RADM）、土壤数据（SOIL）和湍流数据（FLUX），分析吉隆县及周边高寒山区大气边界层结构、天气过程及极端气象事件与泥石流的关联性，并给出关联性排序最高的5个特征因素。

附件逐小时数据中没有逐时泥石流0/1标签，因此本项目没有把所有非灾害小时都当作负样本，也没有训练普通二分类器。本项目采用“2026年事件对照的多尺度异常关联分析”：

1. 以2026年8月26日10:30事件为主研究对象，10:00作为灾前最后一个完整整点。
2. 只用2021—2024年建立历史同期背景。
3. 从题目原始字段构造有明确物理含义、能够回溯到原始字段的多尺度特征。
4. 比较灾前窗口与历史同期窗口的偏离程度，并按关联性排序。
5. 通过48个敏感性场景筛选稳定的前五个特征。
6. 2025年完全不参与筛选、标准化、阈值确定和敏感性检验；主方案冻结后，才按原规则进行独立事件验证。

当前结果属于“单一主事件相对历史背景的关联性排序”，不是泥石流触发因素的因果贡献率，也不是普适预警模型。

供论文人员直接接收的精简包位于`outputs/MathorCup赛道B建模/第一问/`，其中保留总说明、2026主结果、2025独立验证、稳健性材料、4张现有PNG和分离的绘图代码；完整可复现工程仍以本目录为准。

### 2.2 对结果的正确解释

2026年事件前，区域观测站表现为：土壤水分变化偏低、气温偏高、正净辐射偏强、站点降水偏少、空气偏干。这说明事件前区域背景并非典型的“本站短时强降雨型”信号，而更接近暖、干、强辐射环境。

这一结果与公开资料描述的“高位冰崩或冰岩崩塌—碎屑流—泥石流—山洪”灾害链在物理上相容：较高热量和辐射可能反映融化与源区不稳定的环境背景。但本项目不能仅凭一个区域站点的一次事件证明因果关系，也不能据此断言高温或辐射直接导致了泥石流。

特别要写明：观测站位于北纬28.86°、东经85.29°、海拔4140 m，距2026年受灾区约65 km。因此这些指标代表区域气象与地表背景，不等同于灾源区局地降水、冰体温度或坡体含水状态。

### 2.3 原始字段、衍生特征和物理因素的关系

- 原始字段是附件表格中的观测列，如`Ta_2m`、`RH_2m`、`Precip`和各层VWC。
- 衍生特征是由原始字段经过有物理含义的时间累计、均值或变化计算得到的量，如“72小时累计降水”。这才是最终参与比较和报告的具体特征。
- 物理因素是为防止同类变量重复占据前五而设置的分组，如“热量累积”。物理因素组是中间层，不应替代最终具体特征名称。

这样的设计既利用泥石流形成机理构造时间尺度，又保证每个最终结果都能对应回题目给定的原始观测指标。

### 2.4 2025年独立验证结果

冻结2026年的五个特征、公式和预期方向后，以2025年7月8日05:30北京时间的边境口岸首次报告影响为事件参考时间。为排除事件所在小时，主验证窗口截止在04:00；另以05:00做时间敏感性检验。历史背景仍只使用2021—2024年。

主场景中4/5特征方向一致，其中气温偏高、正净辐射偏强和相对湿度偏低达到强支持；土壤含水量变化方向一致但异常强度较弱；72小时累计降水在事件窗口和历史同期的中位数均为0 mm，因此没有复现“降水偏低”的方向。48个敏感性场景全部至少达到4/5方向一致，按计算前写定的标准得到“强验证”。

这里的“强验证”只表示区域背景特征在另一场冰冻圈灾害中具有较好的方向复现性，不能解释为五项因素直接导致冰湖溃决。完整结果见`04_2025独立验证/outputs/05_2025独立验证报告.md`。

## 3. 数据与预处理决策

### 3.1 年份角色

- 2021—2024年：历史同期背景。
- 2025年：未进入任何建模和筛选步骤；主方案冻结后仅用于独立验证。
- 2026年：主事件分析年。

2025年逐小时数据覆盖了事件窗口。独立验证严格沿用冻结后的公式，没有根据2025年结果重选指标或调整方向；由于观测站距Purepu源区约61.6 km，验证对象仍是区域环境背景，而不是源区局地触发条件。

### 3.2 清洗规则

- 数值型缺测占位`9999.9`转换为缺失值，绝不替换成0。
- FLUX中的`NaN`按缺失处理。
- 严格版仅保留`QC=0`的配对观测。
- 扩展版保留`QC=0或4`的配对观测。
- 官方QC含义：0正确、1可疑、2错误、4插补、8缺失、9未质控。
- 降水0表示无降水，与缺测严格区分。
- FLUX没有与本批数据逐列配对的独立QC列；物理关系异常的记录只做复核标记，不在主观判断下直接删除，并在敏感性场景中比较保留与排除两种处理。

2026年事件前24、72和168小时的MET、RADM、SOIL、FLUX数据均有记录；具体覆盖率见`01_数据预处理/outputs/05_事件窗口数据覆盖.csv`。

## 4. 关联性比较与排序方法

本项目不是简单把“2026年一个平均值”和“前几年总平均值”相比。基准场景的事件评价窗口是灾前24小时，历史对照是2021—2024年相同月、日、小时构成的匹配窗口。候选特征自身可使用24、72或168小时的累计或滚动信息。

每个候选特征使用四项互补量度：

1. 稳健标准化差异：用历史中位数和四分位距衡量偏离大小，降低极端值影响。
2. Cliff's delta：衡量事件窗口的数值整体偏高还是偏低，不要求服从正态分布。
3. 匹配时刻超出历史范围比例：逐小时判断2026年是否超出历年同期范围。
4. 历史百分位极端度：判断事件窗口中位数位于历史分布的多极端位置。

四项量度分别排序后合成为候选特征综合名次；随后在每个物理因素组中选一个代表特征，避免温度的多个24/72/168小时版本同时挤占前五。最终顺序采用48场景中的稳定性结果，而非只依赖某一个基准场景。

## 5. 敏感性检验

48个场景由以下组合构成：

- 事件评价窗口：12、24、48小时；
- 历史同期日期带：精确同日、前后3天、前后7天、前后15天；
- 清洗版本：严格版、扩展版；
- FLUX复核点：保留、排除。

稳定性以“进入因素前五的比例、排名中位数与范围、偏离状态一致性、代表指标一致性”衡量。地表湍流热交换只有25%的场景达到可用条件，且在全部48个场景中进入前五的比例仅16.7%，因此没有进入最终稳定前五。

### 7.6 讨论与局限性

建议讨论三点：

1. 暖、干、强辐射与站点少雨背景更支持“非本站强降雨型”的事件解释，但只能称与高位冰岩失稳灾害链相容。
2. 约65 km的空间距离使站点更适合作为区域背景，不能替代灾源区局地观测。
3. 2025年独立验证显示区域背景方向具有跨事件复现性，但两次灾害的启动机制不同，不能据此宣称模型已成为通用预警模型。

## 8. 论文中不能写出的结论

- 不能把五个特征写成对泥石流的“因果贡献率”。
- 不能说观测站降水等于灾源区局地降水。
- 不能把所有非灾害时刻当作负样本。
- 不能把约84个历史灾点当作84个有发生日期的泥石流事件。
- 不能把尼泊尔侧滑坡、洪水和雪崩记录统称为泥石流正样本。
- 不能写成“五个特征全部验证成功”：2025年主场景只有4/5方向一致，累计降水没有复现预期方向。
- 不能说2025年参与了模型训练或指标筛选；它只在规则冻结后使用一次。
- 不能用“当地只有两次泥石流”的表述；只能说公开资料目前可确认至少两次相关重大事件。

## 10. 第一问在论文中的两种模型组织方式

现有代码和结果同时支持下面两种写法。二者使用完全相同的数据、特征和统计量，只是论文叙事方式不同。无论采用哪一种，最终五个特征都应采用48场景稳定性集成后的结果，不能把固定场景的前五名当成最终答案。

### 10.1 写法一：基线模型＋升级模型

这种写法适合论文篇幅较充足，或者希望突出“从单一设定到稳健模型”的改进过程。

#### 基线模型：固定场景的事件—历史同期关联排序

基线模型固定以下设定：

- 主事件：2026年8月26日10:30，灾前截止10:00；
- 历史背景：2021—2024年；
- 事件评价窗口：灾前24小时；
- 历史同期：历年8月26日相同小时，不扩展前后日期带；
- FLUX复核点：保留；
- QC处理：严格版与扩展版分别计算，再对两版统计量取平均；
- 关联性统计量：绝对稳健标准化差异、绝对Cliff's delta、匹配时刻超历史范围比例和历史百分位极端度；
- 先排序候选衍生特征，再在每个物理因素组中选择综合名次最优的代表特征。

基线综合名次可以记为：

`S_j = 四项关联性统计量排名的平均值`，`S_j`越小，特征`j`在固定场景中的关联性越强。

基线结果见`02_特征构造与主分析/outputs/03_物理因素排序.csv`。固定场景前五为：

| 基线排名 | 物理因素 | 固定场景代表特征 |
|---:|---|---|
| 1 | 热量累积 | 72小时平均2米气温 |
| 2 | 土壤湿润状态 | 剖面土壤含水量24小时变化 |
| 3 | 大气湿度与水汽 | 24小时环境水汽压亏缺中位数 |
| 4 | 地表湍流热交换 | 24小时感热与潜热之和中位数 |
| 5 | 降水与水分输入 | 72小时累计降水 |

基线模型的优点是定义直接、计算过程清楚，适合先展示事件窗口与历史同期的差别。它的不足是排序可能依赖人为选定的24小时窗口、精确同日对照、QC口径和FLUX复核点处理；某一固定场景中的高排名不一定具有跨设定稳定性。

#### 升级模型：48场景稳定性集成排序

升级模型不重新发明另一套特征，而是把单一固定场景扩展成预先设定的48个场景：

- 评价窗口：12、24、48小时；
- 历史日期带：精确同日、前后3天、前后7天、前后15天；
- QC版本：严格版、扩展版；
- FLUX复核点：保留、排除。

每个场景都完整执行基线关联排序，然后对物理因素`g`计算：

- 前五入选率：`F_g = 进入前五的场景数 / 48`；
- 因素排名中位数；
- 最优—最差排名范围；
- 偏离机制状态的一致率；
- 各衍生特征成为该因素代表指标的频率。

升级后的最终顺序首先按前五入选率从高到低排列，再结合排名中位数和排名范围判断。每个因素最终报告的具体特征，取其在48个场景中最常成为代表指标的那一个。

升级模型产生了两个重要修正：

1. 固定场景中排名第4的“地表湍流热交换”只有25%的场景达到可用条件，在全部48个场景中进入前五的比例仅16.7%，因此不应进入稳定前五。
2. 固定场景中排名第6的“辐射能量”在48个场景中有91.7%进入前五，稳定性明显更高，因此升级后进入最终前五并排第3。

升级后的最终五个具体特征为：

1. 剖面土壤含水量24小时变化；
2. 24小时平均2米气温；
3. 24小时累计正净辐射；
4. 72小时累计降水；
5. 24小时平均2米相对湿度。

#### 基线＋升级写法的论文结构

可以按以下顺序安排：

1. “固定场景关联排序模型”：介绍基线窗口、四项统计量和组内代表特征。
2. “基线结果及局限”：给出固定场景排序，并指出窗口、QC和缺测完整度可能造成不稳定。
3. “多场景稳健排序模型”：说明48场景组合和稳定性集成规则。
4. “模型升级后的最终五特征”：报告稳定前五，并解释湍流热交换退出、辐射能量进入的原因。
5. “独立事件验证”：用2025年事件验证冻结后的五特征。

这种写法中的“升级”不是简单附加一张敏感性分析表，而是把多个场景的排序结果正式纳入最终决策规则，因此可以称为稳健排序模型或多场景集成模型。

### 10.2 写法二：只写一套多场景稳健关联模型

这种写法适合篇幅紧张的竞赛论文，也是当前更推荐的表达方式。论文不把固定场景单独命名为基线模型，而是把它视为多场景框架中的参考场景。

整套模型可以命名为：

**基于事件—历史同期对照的多尺度稳健关联排序模型。**

模型包含五个连续步骤：

1. 根据泥石流和冰冻圈灾害机理，从题目原始字段构造24、72、168小时尺度的候选特征。
2. 在每个场景中，用稳健标准化差异、Cliff's delta、匹配时刻越界比例和历史百分位极端度衡量关联强度。
3. 在物理因素组内选择代表特征，避免同一原始因素的多个时间尺度重复占据前五。
4. 同时改变评价窗口、历史日期带、QC口径和FLUX处理，形成48个场景。
5. 根据前五入选率、排名中位数、排名范围和代表特征频率，输出最终五个稳定特征，并使用2025年独立事件验证。

在这种写法中：

- `03_物理因素排序.csv`只作为24小时精确同日参考场景，不需要在正文完整展示其前五名；
- `07_物理因素稳定性汇总.csv`和`09_五个关键特征最终结果.csv`是正文的核心结果；
- 敏感性检验不是模型完成后的附属检查，而是最终排序规则的一部分；
- 2025年验证作为模型外部验证，不参与任何参数或指标选择。

#### 单一模型写法的论文结构

可以按以下顺序安排：

1. “机理导向的多尺度特征构建”；
2. “事件—历史同期的稳健关联度计算”；
3. “多场景稳定性集成与因素去重”；
4. “最终五特征及其物理解释”；
5. “2025年独立事件验证”；
6. “局限性与适用范围”。

### 10.3 两种写法如何选择

| 情况 | 建议写法 | 原因 |
|---|---|---|
| 第一问篇幅充足，需要突出模型改进过程 | 基线＋升级 | 能清楚展示为什么不能依赖单一窗口，以及升级如何改变最终排名 |
| 全文篇幅紧张，第一问只是整篇论文的一部分 | 单一稳健模型 | 更紧凑，不会让读者误以为存在两套互相竞争的最终答案 |
| 评委较看重模型创新与稳健性 | 基线＋升级 | 多场景集成可以作为对固定场景模型的实质改进 |
| 评委较看重结论清晰和逻辑统一 | 单一稳健模型 | 从构造特征到稳定排序再到独立验证形成一条主线 |

综合目前材料，优先推荐“单一多场景稳健关联模型”的写法；如果论文人员有足够篇幅，再采用“基线＋升级”展示改进过程。两种写法只能选择一种作为正文主结构，不建议正文先称两套模型、结论部分又混用两套前五名。
