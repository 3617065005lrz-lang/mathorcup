# 数据预处理

## 已完成内容

1. 盘点MET、RADM、SOIL、FLUX逐小时文件。
2. 解析时间字段并检查重复、断点和非整点记录。
3. 统计空值、缺测占位和质量控制码。
4. 核查2025年7月8日和2026年8月26日前后的数据覆盖。
5. 生成严格版和扩展版清洗数据，为主分析和敏感性检验提供统一输入。

## 处理原则

- 不覆盖或改写原始CSV。
- 官方质量控制码为：0正确、1可疑、2错误、4插补、8缺失、9未质控。
- 分别生成“严格样本（QC=0）”和“扩展样本（QC=0或4）”，用于稳健性比较。
- 全文件核查后确认数值型缺测占位为`9999.9`，清洗时转换为缺失值，不用0替代。
- FLUX中的`NaN`按缺失处理；其他极端数值先标记复核，不自动删除。
- 降水为0和降水缺测严格区分。
- 2025年清洗结果未进入2026年主分析；主方案冻结后在`04_2025独立验证`中单独使用。

## 子目录

- `scripts/`：数据检查与清洗脚本。
- `processed/`：严格版与扩展版Parquet数据。
- `outputs/`：数据清单、字段字典、QC分布、事件覆盖和复核记录。
