# 2026年事件主分析

本目录以2026年8月26日10时30分事件为核心，使用2021—2024年历年同期窗口作为对照。2025年整年在本模块中隔离；主方案冻结后，其独立验证在`04_2025独立验证`中完成。

## 最终方法

- 事件截止时刻取北京时间2026年8月26日10:00，即事件发生前最后一个完整整点。
- 排名评价窗口取事件前最后24小时；候选指标本身可以累计此前24、72或168小时。
- 基准对照窗口取2021—2024年每年相同月、日和小时的24小时窗口。
- 灾前7天共168小时用于展示指标演化，不直接作为排名样本窗口，避免7日累计指标额外带入灾前第8—14天信息。
- 从原始指标构造能够回溯到物理因素的多尺度衍生指标。
- 先对候选衍生指标排序，再在每个物理因素组内选择一个代表指标，避免同一因素重复占据前五。
- 严格版和扩展版数据分别计算，比较排序稳定性。
- 敏感性检验改变评价窗口（12/24/48小时）、同期日期带（同日及前后3/7/15天）、QC版本和FLUX复核点处理，共48个场景。
- 2025年不参与候选指标选择、标准化尺度、阈值确定或本模块敏感性检验；冻结后按同一规则独立验证，结果不回流调参。

最终报告五个能够回溯到题目原始字段的具体衍生特征；物理因素组仅用于防止同类指标重复占位。结果是事件关联性排序，不直接解释为灾源区触发因果。

最终五特征表见`outputs/09_五个关键特征最终结果.csv`，论文口径和图表使用说明见上一级`README.md`。
