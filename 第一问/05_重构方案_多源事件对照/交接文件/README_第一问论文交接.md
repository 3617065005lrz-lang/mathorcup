# 第一问最终交接说明

## 一、研究任务与最终定位

本问不是把所有小时简单标记为“泥石流/非泥石流”并训练分类器，而是围绕2026年8月26日吉隆冰岩崩—碎屑流—泥石流—山洪灾害链，识别灾前相对于历史背景最异常、最稳定且具有明确物理意义的五类环境因素。

- 主事件：2026年8月26日事件。
- 源区失稳参考时刻：北京时间约10:52。
- 数据截断：统一使用截至北京时间10:00的数据，防止灾后信息泄漏。
- 历史基准：2021—2024年。
- 2025年：不进入历史基准、模型拟合、标准化、权重或正式排序。
- 研究结论性质：异常关联排序，不是因果贡献率，也不是泥石流发生概率。

## 二、数据角色

### 题目附件数据

题目提供的MET、RADM、SOIL和FLUX逐小时观测是区域观测证据主体，用于描述气温、湿度、辐射、土壤状态、湍流和边界层背景。观测站不等同于灾害源区，论文中不得写成源区实测。

### 外源数据

- ERA5-Land：补充源区附近气温、风场、辐射、土壤温湿度、积雪和融雪状态。
- GPM IMERG Late Run V07：独立核验事件前降水。
- 事件技术资料、DEM和冰川资料：用于解释冰岩崩—泥石流灾害链，不与小时气象变量混作同一种证据。

外源数据的作用是弥补源区空间信息、进行独立核验和加强机理解释，不是脱离题目附件另做一个答案。

## 三、模型主线

原始字段经过质量控制后构造24、48、72、120和168小时的可解释指标；分别建立历史同期对照和同天气型对照；计算稳健Z、历史百分位和历史伪事件随机化概率；在物理组内去冗余；使用熵权法与CRITIC组合确定评价权重；最后通过TOPSIS形成因素排序。

模型完成了以下稳健性检验：

1. 648种场景组合：清洗口径、GMM类别数、同期日期带、源区空间/高程订正、时间窗口和组合权重。
2. GMM随机初值稳定性：主模型采用6类天气型。
3. 1000次历史年份整块自助法：保留年内时间相关性，检验排名对有限历史年份的敏感性。
4. 因素共线性诊断：防止把同一热力过程重复计数。
5. IMERG降水独立核验：检查ERA5-Land与题目站点的降水判断是否一致。
6. LCL旁路敏感性：检查新增边界层湿度指标，但不让重复信息改变正式排序。
7. 2026事件前40天天气型演变：补充天气背景的连续过程解释。
8. 2025跨机理核查：排序完成后再比较方向，不参与模型拟合或权重。

## 四、最终五因素

| 建议顺序 | 物理因素 | 事件前状态 | 论文定位 |
|---:|---|---|---|
| 1 | 空气温度与热量累积 | 偏高 | 核心热力因素 |
| 2 | 土壤湿润状态 | 偏低 | 核心陆面背景因素 |
| 3 | 辐射与地表能量 | 偏高 | 核心能量输入因素 |
| 4 | 大气湿度与干湿状态 | 偏高 | 次稳健暖干背景因素 |
| 5 | 边界层稳定结构 | 偏高 | 不确定性较高的第五因素 |

空气温度、辐射、土壤湿度和大气湿度在年份整块自助法中进入前五的概率分别为97.2%、95.7%、86.9%和81.4%。边界层稳定结构为55.8%，因此第五项不能写成与前三项同等确定。

### 五类物理因素与代表指标

| 物理因素 | 代表指标 |
|---|---|
| 空气温度与热量累积 | 72小时正积温等 |
| 土壤湿润状态 | 土壤含水量变化 |
| 辐射与地表能量 | 平均净辐射或累计正净辐射 |
| 大气湿度与干湿状态 | VPD第90百分位，LCL作为旁证 |
| 边界层稳定结构 | 近地层位温梯度 |

这张表是论文结论的简明汇报口径，不表示每类因素只使用一个字段完成评价。正式计算仍综合多个时间窗口、同期与同天气型两种对照以及同一物理组内的候选指标；表中的指标用于把最终因素明确追溯到题目附件或具有清晰公式的衍生量。衍生指标不能脱离原始字段单独解释，例如72小时正积温仍代表空气温度与热量累积，VPD和LCL仍分别由气温、湿度等原始观测推导。

源区浅层土壤温度在648场景中表现较强，但与空气热量累积在长窗口内高度相关。正式建议将其作为热力机制的源区佐证，不再单列为一个独立主要因素。若论文采用完全按照跨场景频率取前五的口径，可将第五项替换为“土壤温度与冻融”，但必须同时解释其与空气温度的共线性。主文推荐采用上表的去冗余版本。

## 五、最重要的结论边界

- TOPSIS贴近度是综合关联评分，不是因果贡献率或概率。
- 不得写成“模型证明高温导致了泥石流”；应写成“事件前热力相关指标相对历史背景显著偏高，与已知热力型灾害链机理一致”。
- 降水未进入主要因素前五。IMERG显示事件前24、48、72和120小时累计降水均低于历史同期中位数，因此不支持异常强降水主导的解释。
- “土壤湿度偏低”描述题目站点的区域陆面状态，不等于冰体内部、裂隙或沟道完全缺水。
- 地形、冰厚、冰川速度和沟道条件属于易发性与灾害链背景，不能因为未进入小时指标前五就说它们不重要。
- 这是一场事件的前兆异常分析，不能宣称已经建立适用于所有泥石流的普适预测模型。
- 2025年五因素方向一致只能写成跨机理背景一致性，不能写成预测准确率或独立验证成功。
