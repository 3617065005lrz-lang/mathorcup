# 第一问多时间尺度因素写作说明

## 一、核心口径

第一问最终排列的是具有明确物理意义的**因素组**，不是某个时间窗口下的单个变量。24、48、72、120和168 h表示同一物理过程的五种观察尺度，不能把“24 h气温”和“72 h气温”写成两个相互独立的影响因素。

以“空气温度与热量累积”为例，正式模型先分别计算五个窗口下的平均气温、正积温等指标，再将各窗口的同期稳健效应、历史百分位极端度、同天气型效应和随机化支持度进行跨窗口稳健合并，同时计算多窗口方向一致性。TOPSIS所排列的是合并后的基础指标及物理因素。因此，“空气温度与热量累积位列第一”表示该因素在多个合理时间尺度上稳定异常，而不是模型认定某一个窗口是唯一正确窗口。

## 二、正式模型如何合并五个窗口

对基础指标 \(j\) 和窗口集合

\[
\mathcal W=\{24,48,72,120,168\}\ \mathrm{h},
\]

分别得到同期对照和同天气型对照下的稳健效应、百分位极端度及蒙特卡洛概率。正式程序对各评价量采用跨窗口中位数，降低某个窗口偶然极端造成的影响；同时计算五个窗口中异常方向的多数一致比例。随后才进行显著性门控、熵权—CRITIC赋权和TOPSIS排序。

因此，多时间尺度并不是五次互相独立的建模，而是同一因素的稳健性证据。648场景敏感性中的窗口集合变化进一步检查：删除部分窗口或改变窗口组合后，前五因素是否仍然稳定。

## 三、正文统一采用72小时作为展示窗口

为了让正文表格、曲线和因素之间能够直接比较，建议统一用72 h指标作为代表性展示量，原因如下：

1. 72 h位于五个时间尺度中部，兼顾短时变化与持续累积；
2. 三日尺度与热量累积、陆面响应和灾前状态分析具有清楚的物理含义；
3. 所有因素采用同一窗口，可避免根据结果为每个因素分别挑选最有利窗口；
4. 可与第二问三日融水量、72 h降水和动态触发分析衔接；
5. 72 h只是论文展示窗口，不改变正式排名所使用的五窗口综合结果。

正文建议采用下表：

| 最终物理因素 | 72 h代表指标 | 多尺度结论 |
|---|---|---|
| 空气温度与热量累积 | 72 h正积温 | 24—168 h均偏高，24—72 h最突出 |
| 土壤湿润状态 | 72 h多层土壤含水量变化 | 24—168 h均偏低，24—120 h较明显 |
| 辐射与地表能量 | 72 h累计正净辐射 | 24—168 h均偏高，72—120 h较突出 |
| 大气湿度与干湿状态 | 72 h VPD第90百分位 | 24—120 h偏高，168 h方向发生变化 |
| 边界层稳定结构 | 72 h平均位温梯度 | 24—168 h总体偏高，120—168 h较突出 |

其中，VPD在168 h窗口的方向与较短窗口不同，因此只能解释为事件前短—中期暖干信号，不能写成持续一周的稳定干燥异常。

## 四、论文推荐写法

### 方法部分

> 针对每项基础指标，分别构造事件前24、48、72、120和168 h特征。模型对各窗口的同期稳健效应、历史百分位极端度、同天气型效应及随机化支持度进行稳健合并，并以多窗口方向一致性约束偶然异常，最终在物理因素层进行综合排序。因此，时间窗口用于刻画同一因素的不同作用尺度，而不被视为彼此独立的影响因素。

### 结果部分

> 多尺度综合排序表明，空气温度与热量累积为首要异常关联因素。其24—168 h指标均相对历史背景偏高，方向一致率为100%。为保持各因素之间的可比性，正文以72 h正积温作为代表性展示指标，但该因素的排序来自五个窗口的综合评价，而非仅由72 h结果决定。

## 五、主文与附录的分工

- 主文结论表：写“物理因素＋72 h代表指标＋偏离方向＋稳健性”。
- 主文多尺度热图：同时展示24、48、72、120和168 h，证明结论并非依赖单一窗口。
- 附录表：列出每个窗口的事件值、稳健Z、历史百分位和蒙特卡洛概率。
- 讨论部分：说明各因素的主要响应尺度，例如短期暖干、三至五日辐射累积和较长时间的边界层结构变化。

## 六、禁止使用的表述

- 不写“影响最大的因素是72小时气温”。
- 不写“72小时是模型识别出的唯一最佳时间尺度”。
- 不把五个窗口当作五份独立样本。
- 不根据每个因素的最大异常值分别挑选24、48、120或168 h作为正式口径，却不说明选择规则。
- 不把稳健Z、TOPSIS贴近度或窗口入选频率解释为因果贡献率。

如需描述某个因素在哪个窗口最突出，应称为“主要响应窗口”或“峰值异常窗口”，并明确这只是机制解释，不替代五窗口综合排名。
