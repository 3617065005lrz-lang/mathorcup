## 冻结的研究定位

- 主事件：2026年8月26日吉隆冰岩崩—泥石流灾害链。
- 源区启动参考时刻：北京时间约10:52；逐小时数据统一截止到10:00，避免灾后信息进入前兆窗口。
- 研究任务：识别2026年灾前环境状态相对于历史背景的异常性，并对具有明确物理意义的因素进行综合关联排序。
- 不做普通二分类，不把历史小时全部标记为负样本，不把一次事件拆成大量独立正样本。
- 2025年不进入主基准和主排名；其正常时段仅用于敏感性检验，事件本身仅作可选的跨机理附加讨论。

## 数据分层

1. 源区局地层：ERA5-Land、IMERG及可核验的遥感产品，用于描述源区附近热力、水分、积雪和地表状态。
2. 区域观测层：题目MET、RADM、SOIL、FLUX数据，用于描述吉隆高寒山区区域天气、边界层和陆面交换背景。
3. 机理支撑层：DEM、冰厚、冰川速度、遥感变化和传播路径，用于解释链式灾害形成，不与逐小时变量混为同一空间尺度。

## 主模型

原始字段 → 可解释衍生指标 → 历史同期稳健异常 → 天气型条件对照 → 连续块蒙特卡洛 → 物理分组去冗余 → 熵权—CRITIC组合权重 → TOPSIS排序 → 五个物理因素。

## 目录说明

- `config/`：事件口径、数据角色和候选变量字典。
- `docs/`：研究设计、证据登记和论文图表规划。
- `external/`：外部公开项目或资料，仅用于核验，不等于可直接提交的数据。
- `scripts/`：本重构方案的计算脚本。
- `processed/`：计算生成的中间数据缓存。
- `cache/`：特征计算缓存；排序和画图直接读取，不重复清洗原始数据。
- `outputs/`：审计、模型与论文交接结果。
- `plot_cache/`：只供绘图脚本读取的小型缓存。
- `figures/`：正式PNG图片。
- `交接文件/`：面向论文组的最终精简交接包。
