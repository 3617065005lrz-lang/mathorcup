# 第一问阶段结果与论文解释（历史试跑版）

> 本文档记录正式源区数据接入前的阶段结果，不再作为最终数字来源。正式结果请使用`docs/05_正式建模阶段一结果.md`及outputs目录中最新的648场景结果。

## 1. 目前能写出的核心故事

2026年8月26日事件不是典型暴雨型沟谷泥石流，而是高位冰岩体失稳后，经高速下泄、沿程侵蚀裹挟、冰水和河道水补给，转化为碎屑流—泥石流—山洪的灾害链。因此第一问不应写成“用气象站预测泥石流是否发生”，而应写成：

> 在明确灾害链类型和空间代表性边界后，利用源区再分析、区域地气观测和遥感机理证据，识别灾前多时间尺度环境异常，并筛选与事件关系最稳定的五类可解释因素。

## 2. 三层证据如何分工

### 2.1 源区局地层

负责回答“源区附近是否偏暖、是否存在强降水、0℃层是否异常偏高、是否可能发生融雪融冰”。主要数据为ERA5-Land、IMERG和源区DEM高程订正。

### 2.2 区域观测层

负责回答“吉隆高寒山区当时的边界层、辐射、热量、水汽、土壤和湍流背景是否异常”。题目MET、RADM、SOIL、FLUX数据属于这一层，不能直接替代约65 km外源区坡面的绝对状态。

### 2.3 机理支撑层

负责解释“为什么一个高位失稳会演化成巨大灾害链”。包括源区地形势能、裂隙与冻土背景、冰体加载与运动、灾前InSAR形变、沟道松散物和沿程侵蚀裹挟。这些变量缺少统一历史小时序列，所以不与气象时序变量一起竞争前五。

## 3. 当前计算结果

主设定使用2021—2024年历史背景，完全排除2025年；逐小时截止到2026年8月26日10:00，避免把约10:52后的灾害信息泄漏进前兆窗口。

### 3.1 主设定前五

严格清洗版、5类GMM天气型、同期±15天、五窗口共同参与、熵权与CRITIC各占一半时，前五为：

1. 辐射与地表能量：累计正净辐射偏高；
2. 土壤湿润状态：站点剖面含水量持续下降；
3. 空气温度与热量累积：正积温偏高；
4. 大气湿度与干湿状态：高分位VPD偏高；
5. 边界层稳定结构：近地层位温梯度偏高。

### 3.2 162场景稳健性结果

改变清洗口径、天气型数、同期日期带、时间窗口组合和熵权—CRITIC比例后：

- 辐射与地表能量、土壤湿润状态、空气温度与热量累积在100%的场景进入前五；
- 大气湿度与干湿状态在61.1%的场景进入前五；
- 土壤温度与冻融在59.3%的场景进入前五；
- 边界层稳定结构在44.4%的场景进入前五；
- 降水仅在11.1%的场景进入前五，且总体方向偏低。

因此当前更稳健的“候选五因素”是：辐射能量、土壤湿润、空气温度/热量累积、大气干湿、土壤温度；边界层结构是最重要的备选项。这个结论仍需源区ERA5-Land完整重算和IMERG独立降水核验后冻结。

## 4. 物理解释不能写错

### 4.1 辐射、温度和正积温

三者共同指向灾前偏强的区域热力条件。辐射是能量输入，气温是大气热状态，正积温是持续正温的累积表达；它们有关联但不是同一变量。历史同期代表指标间的Spearman相关未达到0.80，当前不需要机械合并。

### 4.2 土壤水分下降和VPD上升

它们说明观测站附近陆面偏干、蒸发需求较强，与强辐射和偏暖状态一致。这不是“干燥直接触发泥石流”，更不能把站点土壤含水量外推为源区冰岩界面含水量。论文应把它们写成区域热—干背景的响应证据。

### 4.3 土壤温度上升

站点浅层土温在多个窗口内相对历史同期上升，可作为陆面受热响应。它不能直接证明源区多年冻土融化；源区冻土退化只能作为需要遥感、地温或多年冻土模型支持的长期机理假说。

### 4.4 降水偏低

“降水没有进入前五”不是说水对灾害链无作用，而是说明在所检验的时间窗口和空间产品中，没有观察到异常强降水前兆。冰体自带水、摩擦或冲击融化、河道水和沿程物质裹挟仍可能显著放大灾害规模。

## 5. 建议的论文表述

建议使用“主要关联因素”“异常背景因素”“区域证据”“源区交叉核验”等词，不使用“原因贡献率”“预测准确率”“气象站证明源区触发”等越界表达。

推荐结论句式：

> 多源事件对照表明，2026年事件前呈现出以偏强辐射、偏高热量累积和区域热—干陆面响应为特征的异常背景，而多尺度降水未表现为稳定湿极端。结合高位冰岩体失稳及沿程裹挟证据，结果更支持热力背景参与的冰冻圈灾害链解释，而不支持将该事件简化为强降雨型泥石流。上述统计关联不等同于单一触发因果。

## 6. 下一步冻结条件

1. 从官方ERA5-Land自行重算源区气温、辐射、积雪/融雪、土壤温湿度和风场；
2. 用IMERG对24、48、72、120、168小时及10/30天降水进行独立核验；
3. 对源区高程、AOI和动态温度递减率做空间支持敏感性；
4. 重跑162场景稳健性矩阵和代表指标冗余诊断；
5. 冻结最终前五后，再制作论文主图，避免先画图后改口径。
