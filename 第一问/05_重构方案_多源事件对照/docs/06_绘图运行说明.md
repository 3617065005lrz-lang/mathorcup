# 第一问绘图运行说明

绘图已与原始数据清洗、特征构造和模型计算完全分开。只有模型结果发生变化时才需要更新绘图缓存；修改配色、字号或版式时，只运行绘图脚本即可。

## 第一次或模型结果更新后

在VS Code中打开本项目根目录，在PowerShell或CMD终端运行：

```powershell
python ".\第一问\05_重构方案_多源事件对照\scripts\29_prepare_formal_plot_cache.py"
python ".\第一问\05_重构方案_多源事件对照\scripts\30_plot_formal_results.py"
```

## 只调整图片样式时

只运行：

```powershell
python ".\第一问\05_重构方案_多源事件对照\scripts\30_plot_formal_results.py"
```

图片只输出为PNG，位置为`figures/`。脚本不生成PDF，也不生成流程图。

当前预设图片包括：主场景因素排序、两类稳健性结果对照、IMERG累计降水独立核验、GMM天气型稳定性诊断、最终五因素的灾前标准化演化，以及2026事件前40天天气型演变。论文中的研究流程图由论文组另行绘制。
