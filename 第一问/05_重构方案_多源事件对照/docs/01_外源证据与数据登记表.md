# 外源证据与数据登记表

## A. 事件事实与机理

### A1. 中国地质调查局事件调查

- 链接：https://www.cgs.gov.cn/ywdt/ddyw/202608/t20260828_867531.html
- 用途：支持源区位于尼泊尔境内、冰崩铲刮冰碛物并演化为泥石流的基本过程。
- 证据等级：官方初步调查。
- 限制：早期报道中的10:30不能直接等同源区启动时刻。

### A2. Guo等2026事件论文

- DOI：https://doi.org/10.1360/CSB-2026-1255
- 用途：支持高位冰岩体失稳、渐进裹挟、冰川运动与多源数据重建。
- 证据等级：事件针对性论文。
- 限制：即时触发机制仍有不确定性；不能把异常温暖直接写成唯一触发原因。

### A3. 水利学报数字孪生研究

- DOI：https://doi.org/10.3724/j.slxb.20260653
- 用途：支持约5150m源区、高位冰岩体失稳、沟道侵蚀裹挟、冰水和河水补给；文章认为灾前约1个月偏暖和一定降雨可能具有促进作用，但不存在明显极端降雨触发条件。
- 证据等级：事件针对性论文。
- 限制：其主要目标是灾害链动力过程模拟，不是气象因素统计排序。

### A4. ICIMOD综合报告

- 链接：https://lib.icimod.org/records/r745z-mvm84
- DOI：https://doi.org/10.53055/ICIMOD.1150
- 用途：将事件界定为链式冰冻圈灾害而非传统冰湖溃决，并整理地震、遥感、无人机和政府资料。
- 证据等级：区域权威机构综合报告。
- 关键补充证据：报告将长期构造损伤、预存裂隙、多年冻土退化、冰雪加载、冰川消融和沟道松散物列为可能共同作用的条件；灾前7月7日至8月24日InSAR在失败区记录到最高约40 cm的视线向形变。
- 关键限制：报告明确指出精确崩塌机制仍在研究；多年冻土退化尚无失败面直接观测；InSAR结果是单轨视线向位移；2025洪水留下的松散物对2026灾害的放大作用仍是假说。

### A5. 多源开放重建

- 链接：https://arxiv.org/abs/2609.04563
- 用途：提供源区几何、历史匹配降水与温度比较；7日ERA5-Land平均气温和正积温异常突出，而多个降水窗口未达到湿极端阈值。
- 证据等级：可复现预印本。
- 限制：作者明确将结果解释为区域热力背景，不是触发证据。

### A6. npj Natural Hazards跨境灾害链研究

- 链接：https://www.nature.com/articles/s44304-026-00271-y
- 用途：给出源区启动的地震学参考时刻02:52:10 UTC，即北京时间10:52:10，并强调源区—传播路径—下游承灾体的跨境连续性。
- 证据等级：同行评议事件论文。
- 限制：事件发生时间可以用于冻结灾前截止点，但不能据此反推某个单一气象触发因素。

### A7. 美国地质调查局事件页

- 链接：https://www.usgs.gov/programs/landslide-hazards/science/2026-nepal-debris-avalanche-and-flash-flood
- 用途：支持冰川相关坡体失稳、冰和水参与、沿沟道裹挟并形成远程泥石流—洪水的过程判断。
- 证据等级：官方事件调查页。
- 限制：页面明确保留“岩体滑坡裹挟冰川”与“冰川崩塌”两种初步解释，论文不应擅自把精确起动机制写死。

## B. 数据产品

### B1. ERA5-Land

- 数据说明：https://essd.copernicus.org/articles/13/4349/2021/
- 用途：源区及邻域逐小时气温、露点、辐射、降水、土壤温湿度、积雪/融雪和风场。
- 典型分辨率：约9km、逐小时。
- 优点：时间长、变量一致、适合历史匹配。
- 限制：陡峻高山地形和冰川坡面为亚格点过程；降水和雪过程误差不可忽略。

### B2. GPM IMERG V07

- 数据页：https://disc.gsfc.nasa.gov/datasets/GPM_3IMERGHH_07/summary
- 用途：以0.1°、半小时降水独立核验ERA5-Land降水。
- 限制：卫星反演在复杂高山和固态降水条件下有误差；Final产品2026档期需要核实，必要时使用Late并明确版本。

### B3. Copernicus DEM GLO-30

- 数据说明：https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
- 用途：源区高程、坡度、坡向、局地起伏和源区—口岸纵剖面。
- 限制：属于DSM；永久冰雪和陡坡区域可能存在局地误差。

### B4. Sentinel-2

- 数据说明：https://developers.google.com/earth-engine/datasets/catalog/sentinel-2
- 用途：灾前后源区光学变化、雪冰和地表覆盖辅助识别。
- 限制：云、阴影和观测间隔会造成临灾盲区；事后变化不能作为灾前预测变量。

### B5. Sentinel-1

- 数据说明：https://developers.google.com/earth-engine/datasets/catalog/sentinel
- 用途：灾前后雷达后向散射变化和云下变化核验。
- 限制：后向散射变化不等于位移；入射角、几何畸变和积雪状态都会影响结果。

## D. 方法性证据

### D1. 高山崩塌与气象变量研究

- 论文：https://doi.org/10.5194/nhess-26-187-2026
- 用途：支持对平均温度、温度振幅、冻融循环、结冰和不同聚合尺度进行分别分析。
- 限制：研究区为欧洲阿尔卑斯，不能直接移植其阈值，只能借鉴变量构造和多尺度思想。

### D2. 复杂地形ERA5-Land高程订正研究

- 论文：https://doi.org/10.1029/2021WR031294
- 用途：说明固定6.5℃/km递减率虽常用，但递减率随时间和空间显著变化；支持优先使用逐日或逐时动态递减率，并把固定递减率放入敏感性检验。
- 限制：研究对象为河流水温建模，不提供吉隆源区可直接套用的递减率。

### D3. ERA5-Land数据论文中的高程订正

- 论文：https://doi.org/10.5194/essd-13-4349-2021
- 用途：ERA5-Land生产系统本身也使用随日变化的环境温度递减率订正气温、气压和湿度，支持“不用一个固定经验值把65 km外站点硬搬到源区”的决策。
- 限制：约9 km格点仍不能解析源区陡坡、坡向、阴影和局地山谷风。

## E. 当前证据结论

1. 热量累积、持续正温、温度振幅、冻融、辐射和融雪应作为重点候选因素。
2. 降水必须保留并进行双产品核验，但不能预设其一定是主要正向触发因素。
3. 站点土壤、辐射、湍流和边界层指标只表征区域背景。
4. 冰川动力、地形和遥感变化用于建立机理链条，不与小时气象指标混成一个缺乏时间对照的统一排名。
5. 所有外源结论都应保留“区域背景不等于坡面直接触发”的限制说明。
6. 灾前InSAR变形、多年冻土背景和沟道预备状态进入机理证据链与论文地图，但不和MET/RADM/SOIL/FLUX的时序异常共同竞争前五。
