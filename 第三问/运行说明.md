# 第三问运行说明

## 1. 在VS Code中

在 VS Code 中打开克隆后的仓库根目录（即包含`第一问`、`第二问`、`第三问`和`第四问`的目录）。

在VS Code终端中确认提示符位于该目录，再运行：

```cmd
python .\第三问\run_models.py
```

单独画图：

```cmd
python .\第三问\run_plots.py
```

图片写入`第三问\figures`，仅生成PNG。画图不会重新建立缓存，也不会重新运行1000情景模型。

## 2. 何时需要重建缓存

只有更换或新增GEFS原始GRIB时才运行：

```cmd
python .\第三问\run_preprocessing.py
```

现有缓存已生成，正常修改图形不需要执行这一步。

## 3. CMD和PowerShell

上述命令在CMD和PowerShell中相同。如果当前终端不在仓库根目录，先进入本仓库。下面的`<仓库路径>`请替换为实际克隆位置：

```cmd
cd /d "<仓库路径>"
```

PowerShell也可以使用：

```powershell
Set-Location "<仓库路径>"
```

## 4. 环境依赖

缺少库时执行：

```cmd
python -m pip install -r .\第三问\requirements.txt
```

`run_models.py`只读取已经存在的缓存、第一问IMERG缓存和第二问最终结果，不联网下载。它会同步生成IMERG起报可用性审计；`run_plots.py`据此额外输出`08_IMERG起报可用降雨审计.png`。
