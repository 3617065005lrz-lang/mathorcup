# 第三问变量与公式说明

## 1. 触发评分

各变量先转换为相对于2021—2024年同期背景的经验百分位：

- `H`：MCD43反照率驱动的72 h增强温度指数融水量ETI百分位；
- `R`：72 h累计降水百分位；
- `A`：15日前期降水百分位与120 h根区土壤水分百分位的中位数；
- `S`：第二问静态空间易发性在源区AOI内的稳健热点值，即第90百分位。

降雨—水分分支、动态触发和时空联合风险为：

`W = sqrt(R × A)`

`D = 1 - (1 - H)(1 - W)`

`J = sqrt(S × D)`

`D`表示热力冰冻圈分支与降雨水分分支中至少一类增强，不是概率；`J`同样是0—1相对风险指数，不是“发生概率”。2026年主事件中热力分支明显强于短时降雨分支，符合热力型触发前提。

## 2. 时间判断

- 关注门控：`J`连续12 h超过第二问2021—2024时空参考分布q80。
- 预警起点：未来第一次持续越阈时刻；若起报时已经越阈，只解释为“应立即进入关注状态”。
- 触发时刻：预测期内最高12 h尾随持续风险窗口的结束时刻。窗口表示截至时刻`t`已经累积完成的前期条件，不能取窗口中心，否则会产生约半个窗口的系统性提前偏差。
- 情景区间：1000个天气—ETI参数—反照率情景的2.5%和97.5%分位数。
- 操作区间：原始情景区间两端各扩展3 h，单独表示6 h原生预报步长带来的时间分辨率限制。
- 预报结构误差：第二问GFS分时效核查得到的温度、降水和短波MAE，以均方根方式并入GEFS集合离散度。由于GFS与GEFS并非完全相同产品，只传递误差下限，不把GFS偏差直接加到GEFS均值。

24、48、72、120、168 h一方面是五个滚动起报提前量，另一方面用于候选前期窗口敏感性。论文中必须将这两个概念分开。

## 3. 统一预警等级

联合风险中位数连续12 h达到历史时空参考q80、q90、q95、q99时，分别记为蓝色、黄色、橙色和红色。四级预警与触发窗口使用同一个联合风险指数，不存在二维矩阵与连续指数各用一套规则的问题。

相邻两次起报共同支持的等级取二者较低等级，只用于判断滚动预报是否稳定，不改变风险指数和等级阈值。四色等级属于样本内历史相对分位，不能写成法定预警标准或发生概率。

## 4. 源区温度

GEFS 2 m温度不能直接代表4991 m源区。模型以第二问经过垂直递减率订正的源区温度作为起报锚点，仅叠加GEFS未来温度变化及集合离散度。因此它表达区域预报对源区热力背景的扰动，而不是把粗网格地表绝对温度强行搬到源区。

## 5. IMERG独立降雨证据

当前IMERG缓存为Late Run V07。由于该产品名义发布延迟约14 h，对起报时刻`t_i`只使用结束时刻不晚于`t_i-14 h`的半小时资料，并分别检查24 h和72 h窗口完整度。完整度低于95%的窗口记为“不可判”，不能把缺测填为零降雨。

IMERG只承担已发生降雨的独立核验；未来降雨仍由GEFS情景提供。因此IMERG分支不会把未来信息泄漏到较早起报，也不会形成另一套最终预警规则。

## 6. 传播模型

沟道分为A—B、B—C、C—D三段。对第`k`段：

`T_k = L_k / V_k`

`T_port = Σ T_k`

速度`V_k`使用由灾后反演范围确定的三角分布。逐情景到达时刻为触发时刻加`T_port`；前缘距离按分段匀速、到达下一段后切换速度计算。

传播参数是2026年事件专属校准量。模型可以回答该灾害链的回放与情景推演，不能直接推广到降雨型泥石流。
