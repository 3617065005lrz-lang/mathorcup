# 第三问论文交接README

## 一、建议的章节主线

第三问建议写成“**机理约束风险外推—集合情景触发窗口—分段传播**”两阶段预报，而不是事件二分类。

1. 继承第二问的热力冰冻圈、降雨水分和空间易发性结构；
2. 用事件发生前真实发布的GEFS滚动起报将动态指标向未来外推；
3. 用1000个相关情景传播天气和ETI参数不确定性；
4. 把触发时间情景输入A—B—C—D传播模型，得到口岸到达时间和沿程距离；
5. 用24、48、72、120、168 h五个提前量展示预报时效与区间宽度的权衡。
6. 用同一联合风险指数给出四色相对预警，并单独展示热力和降雨水分两条分支。
7. 对IMERG Late设置14 h业务可用性截断，防止用事后完整降雨资料冒充起报时已知信息。

## 二、基线和升级模型怎么写

- 基线：GEFS集合均值驱动的确定性机理模型，给出单一危险峰值时刻。
- 升级：GEFS均值—离散度情景、ETI参数范围和反照率误差联合蒙特卡洛，输出情景支持比例及95%区间。

升级模型并未稳定改善点预测中位误差；它的真实价值是揭示不确定性和模型失效边界。论文不要写“升级后精度显著提升”，应写“升级后由单点估计扩展为风险区间，并可诊断提前量增加造成的不确定性扩大”。

## 三、核心结论

- 24 h起报：集合中位触发时刻为08-26 11:00，较核实启动晚约0.13 h；原始95%区间宽39 h并覆盖真值。
- 48 h起报：集合中位触发时刻为08-26 08:00，提前约2.87 h；原始95%区间宽63 h并覆盖真值。
- 72 h及以上：主要提供风险形势，不宜写成精确触发时间预报；72 h中位误差约46.87 h，120 h区间过宽，168 h仍未覆盖。
- 口岸传播时间中位数约7.39 min，95%情景范围约7.12—7.68 min；这与灾后反演参数一致，但不属于独立验证。
- 五个起报在真实时刻均由热力—冰冻圈分支主导；24 h和48 h起报最清楚，符合2026事件非典型强降雨触发的前提。
- 168 h出现过持续橙色、120 h却回落到常态，说明远期等级不稳定；24 h和48 h均达到持续橙色，短临判断更一致。
- 48 h与24 h起报时已可获得的IMERG Late 72 h累计仅5.86 mm和6.40 mm，均低于历史q90=39.83 mm；真实时刻回溯值8.33 mm同样偏低，独立支持热力主导判断。

## 四、可靠性必须怎样表达

五个提前量是同一事件的滚动起报，不是五个独立事件。原始区间4/5覆盖只能写作“滚动起报回放中覆盖4次”，不能写成80%准确率或95%区间具有80%经验覆盖率。

源区静态易发性很高，q80在源区热点处并非稀有报警阈值。它负责判断是否进入持续关注状态，未来风险峰值负责定位危险窗口。情景触发支持比例不是泥石流发生概率。

当前模型适合单事件回放、风险趋势和预警窗口研究，不是可直接部署的完整预警系统。现实部署仍需多个同机理事件、长期历史业务预报、源区连续监测和跨事件检验。

完整的参考论文对比后改动见`交接文件/01_参考论文对比后补充说明.md`；后续制图候选见`交接文件/02_第三问可视化候选图清单.md`；第四问二维动力学结果如何反接第三问见`交接文件/03_第四问动力学结果回接规范.md`。
