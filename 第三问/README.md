# 第三问：触发时间预报与灾害链传播

本目录是第三问的最终工作区。模型回答三个层次的问题：未来何时进入最危险触发窗口、触发后多久到达吉隆口岸、给定若干分钟前缘沿沟道传播多远。

## 一、最终模型

1. **确定性基线**：以GEFS集合均值驱动第二问的机理约束风险模型，未来12小时持续风险峰值作为触发窗口中心。
2. **集合升级**：利用GEFS集合均值与离散度、ETI参数范围和反照率误差构造1000个相关情景，输出触发时刻中位数和95%情景区间。
3. **传播模型**：沿A—B—C—D沟道分段，速度使用三角分布，把触发时间不确定性传播到口岸到达时刻和前缘距离。
4. **五尺度敏感性**：24、48、72、120、168 h统一窗口与主模型并行计算；主模型仍使用第二问预先确定的ETI 72 h、降水72 h、根区水分120 h，不按本次结果事后换窗。
5. **统一预警等级**：联合风险中位数持续12 h越过历史时空q80、q90、q95、q99时，依次进入蓝、黄、橙、红四级；相邻两次起报用于等级稳定性确认。
6. **双机制诊断**：热力—冰冻圈和降雨—水分分支分别输出，再由同一联合风险规则形成最终等级。
7. **独立降雨可用性审计**：IMERG Late Run按名义14 h发布延迟截断，只使用每次起报时已经发布的降雨资料；缺测窗记为不可判，不填成零雨。

模型不使用普通或贝叶斯Logistic。原因不是算法本身不好，而是缺少多个同机理、同空间且具有可靠小时级启动时刻的独立事件，无法形成可信的事件/非事件训练样本。

## 二、事实口径

- 目录参考时刻：2026-08-26 02:52:10 UTC，即北京时间10:52:10。
- 第一阶段脱离：目录时刻后11.9 s，即北京时间10:52:21.9，作为触发真值。
- 大规模运动开始：目录时刻后33.9 s，可作时间真值敏感性。
- 口岸前缘时刻：目录时刻后458 s，即北京时间10:59:48。
- 10:30只是初报时间，不作为物理启动真值。
- 2025年事件不进入背景、阈值或参数标定。
- GEFS 2 m气温只提供未来变化与不确定性，源区温度中心由第二问源区订正结果锚定。

## 三、核心结果

|名义提前量|集合中位触发时刻|中位绝对误差|原始95%区间宽度|操作区间覆盖真值|结论|
|---:|---|---:|---:|---|---|
|168 h|08-20 20:00|134.87 h|155.0 h|否|远期预报仍失效|
|120 h|08-21 19:00|111.87 h|135.0 h|是|区间过宽，仅作形势提示|
|72 h|08-24 12:00|46.87 h|87.0 h|是|趋势预警，不能精确报时|
|48 h|08-26 08:00|2.87 h|63.0 h|是|能够定位事件日高危窗口|
|24 h|08-26 11:00|0.13 h|39.0 h|是|点预测最接近真值|

“操作区间”是在原始情景区间两端各扩展3小时，以承认GEFS原始6小时步长。升级后的原始情景区间已经覆盖五次滚动起报中的四次；论文仍必须同时报告两种区间。五个起报属于同一事件，不是五个独立事件，4/5覆盖不能写成80%准确率。

传播模型得到源区至口岸地形修正路径约21.681 km，传播时间中位数约7.39 min，95%情景范围约7.12—7.68 min。速度范围来自本事件灾后反演，因此这是参数校准后的事件回放一致性，不是跨事件独立预测精度。

五个起报在真实启动时刻均由热力—冰冻圈分支占主导。168 h起报的较高等级在120 h起报中消失，说明远期结果有明显跳变；24 h与48 h起报均达到持续橙色，短临判断较一致。论文不能把168 h单次结果写成“提前7天成功预警”。

IMERG Late独立核验进一步表明：按14 h资料延迟截断后，48 h与24 h起报时可获得的完整72 h累计降雨分别为5.86 mm和6.40 mm，均远低于历史q90=39.83 mm；真实启动时刻回溯72 h累计为8.33 mm。这支持“非强降雨主导”，但不等于降雨完全无作用。168、120、72 h起报的72 h资料窗不完整，只能记为不可判。

## 四、目录

- `cache/`：GEFS源区点预报缓存。
- `processed/`：逐情景触发时间、逐时风险、到达时间和距离样本。
- `outputs/`：可直接引用的表格和结果说明。
- `figures/`：运行绘图脚本后生成PNG，不输出PDF。
- `scripts/`：下载、缓存、模型、评估和绘图脚本。
- `外源资料/`：事件证据、GEFS、传播参数与承灾体资料。
- `交接文件/`：参考论文对比后补充、可视化候选库和第四问回接规范。
- `运行说明.md`：VS Code、CMD和PowerShell命令。
- `变量与公式说明.md`：论文公式及变量解释。
- `论文交接README.md`：论文写作者应如何使用结果。

新增的独立降雨审计见`outputs/21_IMERG起报可用性审计.csv`和`outputs/22_IMERG业务解释与降雨分支核验.md`；对应图片为`figures/08_IMERG起报可用降雨审计.png`。

第三问中哪些内容已经完成、哪些必须等待第四问二维动力学结果后才能写，见`交接文件/04_第三问等待第四问回接内容清单.md`。第四问只升级空间传播与承灾体影响，不要求重做第三问的触发时间模型。

## 五、运行入口

从克隆后的仓库根目录运行：

