# 第四问最终检查改进

## 一、最终任务定位

第四问的核心目标是针对2026年吉隆泥石流灾害链构建本地化仿真环境，复现高位崩塌物源从源区进入沟谷、侵蚀卷入、沿河谷传播并影响吉隆口岸的全过程。因此，模型的首要评价对象是“吉隆源区—口岸全灾害链覆盖复现”，而不是要求模型直接迁移到其他地区。

空间扩展性和下游独立检验继续保留，但作为模型稳健性的补充证据，不反过来取代吉隆本地灾害链复现这一主目标。

## 二、最终模型结构

模型采用深度平均浅水动力框架，并使用分区Voellmy摩阻描述泥石流与普通洪水在底部阻力方面的差异：

1. 源区沟谷段与汇入河谷后的传播段采用不同的有效摩阻系数与湍流阻力参数；
2. 设置侵蚀卷入项，使运动体积随传播过程变化；
3. 采用30 m DEM作为正式计算网格，60 m结果用于分辨率—地形离散联合敏感性检验；
4. 以到达口岸时间区间、卫星识别灾害范围、传播廊道和物理可接受性共同约束参数；
5. 通过拉丁超立方粗筛、局部加密搜索和GLUE有效情景集合表达参数不确定性。

所有摩阻和侵蚀参数均解释为当前栅格尺度下的有效参数，不作为可直接移植到其他沟谷的材料常数。

## 三、本轮最终改进

### 1. 到达时间由单点改为证据区间

到达时间不再强行按单一秒数标定，而采用458—463 s的观测区间。模拟结果位于该区间时不再人为区分秒级优劣，避免把初报、视频判读和时钟误差伪装成精确真值。

### 2. 重新确定主评价层级

最终评价顺序确定为：

> 吉隆全灾害链覆盖复现 → 增量运动范围检验 → 下游空间扩展性检验。

初始源区属于本次仿真环境的已知边界条件，因此在全灾害链复现中纳入源区是合理的。与此同时，另行计算扣除初始物源后的增量流深，避免仅依靠预设源区获得较高结果。

### 3. 全灾害链目标专项调参

在现有有效情景基础上，对GLUE温度系数和条件概率阈值进行网格搜索。选择过程只使用吉隆源区至口岸的本地标定范围，并按上游链距划分四个空间块，以四块CSI均值减0.25倍标准差作为稳健性目标。

最终选择：

- GLUE温度系数：10.0；
- 全灾害链条件概率阈值：0.04；
- 下游留出区不参与上述参数选择。

### 4. 防止单纯扩大范围获得高覆盖率

全灾害链主结果同时报告覆盖率、CSI和精确率。覆盖率衡量卫星识别灾害区有多少被模型复现；CSI与精确率同时惩罚模拟范围越出卫星识别区，防止通过无限扩大灾害范围获得虚高覆盖率。

### 5. 两阶段局部参数搜索

在首轮优良情景附近追加16组局部拉丁超立方情景。结果表明，继续追逐单一情景的标定分数容易降低空间迁移能力，因此最终范围结论采用GLUE集合，不采用某一个最高分情景代表全部参数不确定性。

### 6. 统一评价口径

正式仿真区分两类流深：

- 总最大流深：用于评价包括已知源区在内的完整灾害链覆盖复现；
- 最大增量流深：扣除初始物源影响，用于检验真实运动与侵蚀传播范围。

两类结果分别命名、分别报告，不再混用。

## 四、最终结果

|评价内容|最终结果|论文中的作用|
|---|---:|---|
|吉隆源区—口岸全灾害链覆盖率|0.725|第四问正文主结果|
|全灾害链CSI|0.700|惩罚模拟范围越界|
|全灾害链精确率|0.954|证明高覆盖率并非依靠无限扩张|
|增量运动范围标定区CSI|0.682|扣除初始物源后的严格动力检验|
|下游独立空间迁移CSI|0.602|区域内部空间扩展性补充检验|

全灾害链覆盖率由原约0.714提高至0.725。对应CSI仍达到0.700、精确率达到0.954，说明改进同时兼顾覆盖能力和空间边界一致性。

## 五、可靠性与不确定性检查

1. 代表情景与GLUE集合均未利用下游留出区进行参数选择；
2. 30 m与60 m差异仅解释为分辨率—地形离散联合敏感性，不冒充严格网格收敛；
3. 宽域重跑未发现当前计算域截断主要传播过程；
4. 单像元最大流深、最大流速和最大冲击强度对局部地形敏感，正式数值解释优先使用P99或P99.9；
5. GLUE权重代表当前证据约束下各有效情景的相对支持度，不解释为严格贝叶斯后验概率；
6. 当前结果适用于2026年吉隆热力—冰岩失稳型灾害链，不直接替代降雨型泥石流模型。

## 六、与第三问的最终衔接

第四问向第三问回传：

- 条件影响范围及核心、主要、外围三个空间层级；
- GLUE传播时间情景；
- 口岸到达时间及其不确定性；
- 流深、流速、冲击强度和侵蚀厚度栅格。

第三问的触发时间情景与第四问传播时间情景采用全组合方式传播。约7 min的运动传播不确定性小于第三问天气触发时刻的不确定性，因此总体预警区间主要由触发时间控制。

## 七、最终结论

第四问已经完成模型结构、参数标定、全灾害链专项调参、严格动力检验、空间扩展检验和第三问回接。当前主结果能够较好复现吉隆本地灾害链，并通过CSI、精确率和补充独立检验证明结果不是单纯依靠扩大灾害范围获得。

在缺少更高分辨率DEM、连续现场流深/速度观测和更精确物源体积证据的情况下，继续增加参数搜索的预期收益较小，且会提高单事件过拟合风险。因此，本版本可作为第四问最终建模结果。
