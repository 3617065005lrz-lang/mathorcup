## 编译

解压源码包或下载本目录，在此目录用XeLaTeX编译两次 `main.tex`。独立预览中的章节、公式及图表计数器仅用于承接总稿编号；正式合并时只引入 `sections/question3.tex` 和所需图片。

字体和参考文献配置沿用队友模板。模板同时调用Times New Roman、Arial及楷体，需编译环境支持这些系统字体。
