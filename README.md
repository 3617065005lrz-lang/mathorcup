# MathorCup 赛道 B 建模项目

本仓库保存赛道 B 四个问题的建模代码、关键数据、结果表格、论文图件与复现说明。项目围绕高位冰岩崩塌—泥石流灾害链展开，依次完成影响因素识别、时空风险评价、触发与传播预报，以及二维动力学回放。

> 仓库保留了研究过程与正式成果。阅读或引用时，请优先进入各问题标明的“正式模型”或“论文交接”目录，不要将早期探索结果当作最终结论。

## 仓库结构

```text
mathorcup/
├─ 第一问/                    # 正式入口：05_重构方案_多源事件对照
├─ 第二问/                    # 正式入口：07_正式模型_外源数据融合
├─ 第三问/                    # 触发时间与传播模型
├─ 第四问/                    # 二维动力学模型
└─ 最终检查改进/              # 跨问题一致性审计
```

各模块通常采用以下分层：

- `scripts/` 或 `run_*.py`：预处理、建模、分析与绘图入口；
- `config/`：事件口径与模型配置；
- `cache/`、`processed/`：可重建的中间数据；
- `outputs/`：数值结果、审计表和结果说明；
- `figures/`：论文候选 PNG 图件；
- `交接文件/`：面向论文写作的结论、边界和图表清单。

## 环境与运行

建议使用 Python 3.10 或 3.11，并为项目建立独立虚拟环境。第二、三、四问分别维护依赖文件，避免地理空间库与数值计算库之间的版本冲突：

```powershell
# 在仓库根目录执行；按实际需要安装对应模块
python -m pip install -r ".\第二问\07_正式模型_外源数据融合\requirements.txt"
python -m pip install -r ".\第三问\requirements.txt"
python -m pip install -r ".\第四问\requirements.txt"
```

常用复现入口：

```powershell
# 第三问：基于已有缓存重跑模型与绘图
python ".\第三问\run_models.py"
python ".\第三问\run_plots.py"

# 第四问：基于已有结果重新生成表格、栅格与图件
Push-Location ".\第四问"
python ".\run_plots.py"
Pop-Location
```

第一、二、四问的完整计算步骤较长，运行前请阅读对应的运行说明。默认优先复用仓库内已有结果；只有在原始数据、参数或求解器发生变化时，才需要重建大型缓存或完整重跑。
